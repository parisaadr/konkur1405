# تخمین‌گر تراز و رتبهٔ کنکور ۱۴۰۵

یک صفحهٔ وب کاملاً استاتیک (بدون نیاز به سرور یا بک‌اند) که با گرفتن نمرات نهایی
پایهٔ یازدهم و دوازدهم و درصدهای کنکور، یک **نمرهٔ کل تقریبی**، **بازهٔ تخمینی
رتبه** و **سطح تقریبی دانشگاه‌های قابل‌قبولی** را بر اساس قوانین کنکور سراسری
۱۴۰۵ نشان می‌دهد.

> ساخته‌شده با کمک هوش مصنوعی (Claude). همهٔ محاسبات کاملاً در مرورگر خود
> کاربر انجام می‌شود؛ هیچ داده‌ای به هیچ سروری ارسال نمی‌شود و پروژه هیچ
> بک‌اندی ندارد.

---

## ⚠️ این ابزار چیست و چه چیزی نیست

**هست:** یک تخمین آموزشیِ شفاف که از روی قوانین رسمیِ اعلام‌شده برای سهم سوابق
تحصیلی و ضرایب دروس، یک نمرهٔ کل قابل‌فهم می‌سازد و آن را با یک مدل آماریِ
ساده (و **قابل‌تنظیم**) به بازهٔ رتبه تبدیل می‌کند.

**نیست:** جایگزین تراز رسمی سازمان سنجش. تراز واقعی از روی میانگین و
انحراف‌معیارِ **واقعیِ نمرات همهٔ داوطلبان همان سال** محاسبه می‌شود — آماری که
فقط داخل سازمان سنجش موجود است و منتشر نمی‌شود. هیچ ابزاری بیرون از آن سازمان
(این یکی هم همین‌طور) نمی‌تواند تراز رسمی را عیناً بازتولید کند.

به همین دلیل:

- خروجی «رتبه» همیشه به‌صورت یک **بازه** نشان داده می‌شود، نه یک عدد قطعی.
- بخش «چه دانشگاهی قبول می‌شوم» به‌صورت **سطح‌بندیِ کیفی** (نه اسم دانشگاه و
  رتبهٔ دقیق) ارائه می‌شود، چون آخرین رتبهٔ قبولی هر رشته-دانشگاه هرسال با
  ظرفیت، سهمیه‌ها و رقابت همان سال تغییر می‌کند.
- کاربر می‌تواند میانگین، انحراف‌معیار فرضی و تعداد داوطلبان را در «تنظیمات
  پیشرفته» خودش تغییر دهد.

برای انتخاب رشتهٔ نهایی، همیشه کنار این ابزار از **کارنامهٔ رسمی خودتان**،
سایت رسمی سازمان سنجش (**sanjesh.org**) و یک مشاور مطمئن هم استفاده کنید.

## روش محاسبه (خلاصه)

۱. **سهم سوابق تحصیلی از نمرهٔ کل**
   - گروه‌های ریاضی، تجربی، انسانی: ۶۰٪ (۴۳٪ از معدل کتبی پایهٔ دوازدهم با
     «تأثیر قطعی» + ۱۷٪ از معدل ۶ درسِ پایهٔ یازدهم با «تأثیر مثبت»، یعنی فقط
     در صورتی لحاظ می‌شود که نتیجه را بهتر کند).
   - گروه‌های هنر و زبان‌های خارجی: ۳۰٪ (با همان نسبتِ داخلیِ ۴۳:۱۷، چون
     اطلاعیهٔ رسمیِ جداگانه‌ای برای تفکیک دقیق این دو گروه پیدا نشد — این
     نکته به‌صراحت در برنامه هم اعلام شده).

۲. **سهم آزمون تستی اختصاصی**
   - گروه‌های ریاضی، تجربی، انسانی: ۴۰٪
   - گروه‌های هنر و زبان: ۷۰٪
   - دروس عمومی (ادبیات فارسی، عربی، دین‌وزندگی، زبان خارجه) از دفترچهٔ آزمون
     تستی حذف شده‌اند و فقط از طریق سوابق تحصیلی اثر می‌گذارند.

۳. **ترکیب با ضریب دروس** → یک «نمرهٔ کل» بین ۰ تا ۱۰۰ (ضرایب پیش‌فرض از منابع
   آموزشی عمومی گرفته شده و در جدول ماشین‌حساب کاملاً قابل‌ویرایش‌اند).

۴. **تبدیل به بازهٔ رتبه** با فرمول نمرهٔ استاندارد آماری:

   ```
   z = (نمرهٔ کل − میانگین فرضی) ÷ انحراف‌معیار فرضی
   درصد از بالا ≈ تابع توزیع نرمال روی z
   رتبهٔ تقریبی ≈ (درصد از بالا) × (تعداد تقریبی داوطلبان گروه)
   ```

   میانگین و انحراف‌معیارِ پیش‌فرض برای هر گروه در `js/data.js` تعریف شده‌اند
   و صرفاً **فرض‌های آماری** هستند، نه آمار رسمی سازمان سنجش. برای نشان‌دادن
   صادقانهٔ عدم‌قطعیت، به‌جای یک عدد، یک بازه (±۰.۳۵ انحراف‌معیار روی z) نمایش
   داده می‌شود.

جزئیات کامل‌تر و منابع هر بخش، در خودِ صفحه (بخش «روش محاسبه») هم آمده.

## ساختار پروژه

```
konkur1405/
├── index.html          صفحهٔ اصلی (فرم، نتیجه، توضیحات، پرسش‌های پرتکرار)
├── css/
│   └── style.css       طراحی و تم بصری
├── js/
│   ├── data.js          «پایگاه داده»: ضرایب دروس، سهم‌ها، لایه‌های دانشگاهی، منابع
│   ├── calc.js           منطق خالص محاسبه (بدون هیچ دستکاری DOM)
│   └── app.js            اتصال داده و منطق به فرم و نمایش نتیجه
├── README.md            همین فایل
└── LICENSE
```

این جداسازی عمدی است: اگر فقط خبر تازه‌ای دربارهٔ تغییر ضرایب یا سهم سوابق
تحصیلی شنیدید، کافی‌ست فقط `js/data.js` را ویرایش کنید — نیازی به دست‌زدن به
HTML یا منطق محاسبه نیست.

## چطور روی گیت‌هاب آپلود و اجرا کنم؟ (GitHub Pages)

این پروژه کاملاً استاتیک است، پس نیازی به build یا نصب پکیج ندارد.

1. یک ریپازیتوری تازه در گیت‌هاب بسازید (مثلاً `konkur1405`).
2. همهٔ فایل‌های همین پوشه (`index.html`، `css/`، `js/`، `README.md`،
   `LICENSE`) را در ریشهٔ همان ریپازیتوری آپلود/پوش کنید:

   ```bash
   git init
   git add .
   git commit -m "اولین نسخهٔ تخمین‌گر تراز و رتبهٔ کنکور ۱۴۰۵"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo-name>.git
   git push -u origin main
   ```

3. در گیت‌هاب بروید به: **Settings → Pages**
4. زیر «Build and deployment» → «Source» گزینهٔ **Deploy from a branch** را
   انتخاب کنید، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب کنید و «Save» بزنید.
5. بعد از چند دقیقه، سایت روی آدرسی مثل زیر در دسترس خواهد بود:

   ```
   https://<username>.github.io/<repo-name>/
   ```

نیازی به هیچ تنظیم دیگری (دیتابیس، متغیر محیطی، API key) نیست — همه‌چیز در
مرورگر خود کاربر اجرا می‌شود.

## چطور اطلاعات را برای سال بعد یا تغییرات جدید به‌روز کنم؟

فایل `js/data.js` را باز کنید:

- برای تغییر **سهم سوابق تحصیلی / آزمون تستی**، شیء `WEIGHTS` را ویرایش کنید.
- برای تغییر **ضریب دروس**، آرایه‌های `general` و `specific` هر گروه در
  `GROUPS` را ویرایش کنید.
- برای تغییر **تعداد تقریبی داوطلبان** یا **میانگین/انحراف‌معیار فرضی**،
  فیلدهای `candidatesApprox`، `assumedMean` و `assumedSD` هر گروه را عوض
  کنید.
- برای تغییر **توضیح سطح دانشگاه‌ها**، آرایهٔ `tiers` هر گروه را ویرایش کنید.
- تاریخ آخرین بررسی را در `META.lastVerified` و منابع را در `META.sources`
  به‌روز نگه دارید (این‌ها الان فقط در HTML به‌صورت دستی هم نوشته شده‌اند —
  اگر خواستید، می‌توانید در `app.js` این بخش‌ها را از روی `META` هم رندر کنید
  تا فقط یک‌جا نگه‌داری شوند).
